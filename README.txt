TEAM OCTAESPORTS WEBSITE STARTER
================================

Files
- index.html: complete responsive one-page website prototype.
- README.txt: setup and launch checklist.

PREVIEW LOCALLY
1. Extract the ZIP.
2. Double-click index.html to open it in Chrome.
3. Edit the text and links in a code editor such as Visual Studio Code.

BEFORE PUBLISHING
1. Replace the second owner's name and bio.
2. Replace the sample owner/player initials with actual photos.
   For each card, replace <div class="placeholder">...</div> with:
   <img src="images/player-name.jpg" alt="Player name">
   Create an images folder and put the photo file inside it.
3. Verify all player roles and bios.
4. Replace the YouTube link with the official Octa YouTube channel URL.
5. Confirm the Instagram link and email.
6. The contact form uses mailto, so it opens the visitor's email app. For a form that sends directly from the site, connect a form backend/service before launch.

PUBLISH FREE WITH VERCEL (high-level)
1. Create a GitHub account if you don't have one.
2. Create a new repository and upload index.html (and your images folder).
3. Sign in to Vercel and import that repository as a project.
4. Deploy. Vercel will give you a temporary *.vercel.app address.
5. In Vercel project Settings -> Domains, add your purchased domain and follow the exact DNS instructions Vercel provides.
6. Buy/register teamoctaesports.com (if available) from a domain registrar. Domain availability has not been checked here.
7. After domain setup, verify both the root domain and www version as appropriate.

GOOGLE SEARCH
1. After the site is live on your own domain, open Google Search Console.
2. Verify domain ownership using the method Google gives you.
3. Submit a sitemap if you add one, and request indexing for the homepage.
4. Google indexing is not instant and cannot be guaranteed. Search visibility can take days or weeks and depends on indexing and site quality.

IMPORTANT
This is a starter website, not yet published. The domain is not purchased or connected by this ZIP. No owner photos or official YouTube URL were supplied, so placeholders are used.
